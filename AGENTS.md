# CV Writer Project & Agent Instructions

This repository contains a stateless Model Context Protocol (MCP) server written in Rust that enables AI Agents to synthesize user profiles into professional CVs/resumes formatted with the "Star Rover" template and compiled via LuaLaTeX.

## Operating Guidelines

This project strictly operates under a 7-role Scrum Team:
- **Product Owner (PO)**: User value, agent usability, interface simplicity.
- **Business Analyst (BA)**: Domain entities, JSON schemas, edge case mappings.
- **Project Manager (PM)**: Deliverable tracking, stateless constraints, Docker runtime readiness.
- **System Architect (SA)**: Pipeline architecture, ephemeral sandbox isolation, MCP protocol integrity.
- **Tech Lead**: LuaLaTeX modernization, modern OpenType typography, idiomatic Rust.
- **Developer**: Code implementation, templating, compilation runner, Docker build.
- **Quality Control (QC)**: Black box verification, input stress testing, artifact inspection, zero-residue check.

Refer to `.agents/rules/scrum_team.md` and `.agents/skills/cv-writer-scrum-team/SKILL.md` for full definitions and procedures.
